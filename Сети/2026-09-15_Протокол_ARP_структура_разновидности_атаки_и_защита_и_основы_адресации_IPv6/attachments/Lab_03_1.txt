1. Собрать топологию по рисунку Lab_03_1.png

2. На маршрутизаторе R1 назначить IP адрес 192.168.0.1/24 интерфейсу Fastethernet 0/0 и включить его:
(маску требуется указать "длинную")
Команда назначения адреса:
Router(config-if)#ip address IP MASK

- интерфейс необходимо включить, команда "no shutdown"
- проверка результата (назначения адреса) "show ip interface brief"

3. Назначить интерфейсу на маршрутизаторе R2 адрес 192.168.0.2/24
- проверить с помощью команды ping наличие связи между маршрутизаторами

4. Настроить удаленный доступ к консоли управления с использованием протокола telnet c защитой его паролем:
(сразу 5 входов, пароль задается одинаковый на все входы сразу)
Router(config)#line vty 0 4
Router(config-line)#login
Router(config-line)#password telnet

5. Настроить защиту доступа к консоли (консольное подключение только одно) :
Router(config)#line console 0
Router(config-line)#login
Router(config-line)#password console

6. Выполнить переподключение к R1 через консольный порт (в GNS3 достаточно клика мышью по устройству, 
и разорвать текущую сессию - несколько раз "exit").
- пароль запрошен? 
- переход в администраторский режим возможен?

7. Выполнить подключение с R2 к R1 через сеть по протоколу telnet ("telnet IP") и перехватить пакеты этого сеанса.
- пароль запрошен?
- переход в администраторский режим возможен?
- какой пароль дает доступ в enable mode? 
- отфильтровать трафик по имени протокола (telnet)
- в каком виде передается трафик?

8. Выполнить настройку пароля администратора:
enable password network

9. Отключиться от маршрутизатора от обоих типов подключений

10. Повторить пункты 6 и 7.
- что изменилось?

11. Выполнить просмотр текущей рабочей конфигурации:
Router#show running-config

- в каком виде хранятся пароли?

12. Выполнить задание секретного пароля администратора:
enable secret network2

13. повторить пункт 11.
- что изменилось?

14. Включить сервис шифрования паролей:
Router(config)#service password-encryption 

15. повторить рункт 11.
- что изменилось?

16. Настроить удаленный доступ к консоли управления коммутатором с использованием протокола telnet 
c защитой его паролем (здесь учесть тот факт, что порты коммутатора IP адресов не имеют и адресовать 
нужно будет SVI vlan1 для Default VLAN):

- Назначение адреса VLAN, адрес опять 192.168.0.1/24:
ESW(config)#interface vlan 1
- далее обычным образом назначается адрес и включается интерфейс

- назначить R3 IP адрес 192.168.0.2/24
- проверить связность (в отличие от предыдущего упражнения, R3 можно подключить к ЛЮБОМУ порту коммутатора - f1/0-f1/15)

- выполнить аналогично маршрутизатору задание пароля на доступ через telnet и включить его шифрование.
- настроить защищенный пароль администратора.
- убедиться в том, что пароли в конфигурации скрыты, а контроль доступа работает, т.е. при подключении по telnet пароли запрашиваются.

17. Разграничение доступа к telnet-интерфейсу сетевых устройств:
- настроить простой список контроля доступа, разрешающий доступ узлу с адресом 192.168.0.2:
Switch(config)#access-list 1 permit 192.168.0.2

- назначить созданный список доступа на telnet-интерфейс:
Switch(config)#line vty 0
Switch(config-line)#access-class 1 in

18. Убедиться, что доступ к консоли через telnet протокол для R3 сохранился.

19. Добавить к коммуатору маршрутизатор R4 и назначить ему адрес 192.168.0.3/24
- убедиться в наличии связности
- убедиться, что новому узлу в доступе к коммутатору через telnet протокол будет отказано.

20. Выполнить на коммутаторе, подключившись к нему любым доступным способом, команду:

- есть ли информация о неуспешных подключениях?

25. Удалить файл startup-config:
- Убедиться в существовании файла startup-config, командой:
SW#dir all-filesystems

- Выполнить ОДНУ из команд:
SW#write erase
SW#delete nvram:/startup-config
- После любой из этих команд надо убедиться, что файла больше нет (возможен вариант, что файл
присутствует, но его длина равна нулю).
